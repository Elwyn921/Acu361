Acu361 gives millimetre coordinates of all 361 acupoints of the WHO standard (670 points), each placed by an acupuncturist on the skin of an open anatomical body with seven layers, together with the surface lines of the 14 meridians and the proportional bone measurements in B-cun.

Acu361 给出 WHO 标准全部 361 个经穴（共 670 个点）的毫米级三维坐标。每个点由针灸师在一具带七层解剖结构的开放人体模型的皮肤上逐一定位，并附 14 条经脉的体表经线和以 B-cun 计的骨度分寸。

Coordinate frame坐标系

  • Units单位millimetres毫米
  • +xtoward the body's left指向身体左侧
  • +yup向上
  • +zanterior: the body faces +z向前：人体面向 +z
  • Handedness手性right-handed, the glTF convention右手系，与 glTF 约定一致
  • Origin原点x = 0 is the mid-sagittal plane; the soles are at y = 0x = 0 为正中矢状面；脚底在 y = 0

The JSON and GLB files share this frame, so points, lines and rulers overlay the body without any transform.JSON 与 GLB 文件共用这一坐标系，点、经线和分寸尺无需任何变换即可叠加到人体上。

Using the data使用方法

import json
import numpy as np

doc = json.load(open("data/points.json", encoding="utf-8"))
points = {p["id"]: p for p in doc["points"]}
xyz = np.array([p["pos"] for p in doc["points"]])   # (670, 3), mm

p = points["LU7_L"]
print(p["code"], p["name_pinyin"], p["name_zh"], p["pos"])
print(p["nearest_bone"], p["bone_distance_mm"], "mm")

# or as a table
import pandas as pd
df = pd.read_csv("data/points.csv")              # x_mm, y_mm, z_mm columns
import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const scene = new THREE.Scene();          // units: mm, +y up, the body faces +z

new GLTFLoader().load('data/body/skin.glb', (gltf) => {
  const skin = new THREE.MeshStandardMaterial({ color: 0xe6d8c6, side: THREE.DoubleSide });
  gltf.scene.traverse((o) => { if (o.isMesh) o.material = skin; });
  scene.add(gltf.scene);
});

const { points } = await (await fetch('data/points.json')).json();
const dot = new THREE.SphereGeometry(3);
for (const p of points) {
  const m = new THREE.Mesh(dot, new THREE.MeshBasicMaterial({ color: 0xb4432f }));
  m.position.fromArray(p.pos);
  m.name = p.id;                          // e.g. "LU7_L"
  scene.add(m);
}

The GLB files have no materials; render them double-sided. Node names are the Z-Anatomy object names (e.g. Radius.l), and nearest_bone uses the same names.GLB 文件不含材质，请用双面材质渲染。节点名即 Z-Anatomy 结构名（如 Radius.l），nearest_bone 使用同样的名字。

How the points were placed标注方式

An acupuncturist located the 361 acupoints one by one in a 3D annotation tool developed by the lab, working directly on the skin of the standing Z-Anatomy body, and finalized every position. Point codes, the set of points and their order follow the WHO Standard Acupuncture Point Locations in the Western Pacific Region (2008).

针灸师在实验室自研的三维标注工具中，直接在 Z-Anatomy 立位人体的皮肤上逐一定位 361 个经穴，并逐个定稿。穴位编码、穴位集合及其顺序依照《WHO 西太平洋地区标准针灸穴位定位》（2008）。

Bilateral points are left–right symmetric: each right-side point is the mirror image (x → −x) of its left-side counterpart. The nearest bone and the distance to it were computed on the bone layer of the same body. The meridian lines follow the shortest path over the skin between consecutive points, smoothed, resampled about every 4 mm and offset 1.2 mm outward; only the course on the body surface is drawn.

双侧穴位左右对称：每个右侧点都是其左侧点的镜像（x → −x）。最近骨与到骨距离在同一具人体的骨层上计算。经线沿皮肤表面连接相邻穴位的最短路径，经平滑、约每 4 mm 重采样并向外偏移 1.2 mm；只画体表循行。

Limitations局限

  • One body.单一人体。 All points are on a single adult male model in standing posture. Using them on another body needs registration or a proportional (B-cun) mapping.所有点都在一具成年男性立位模型上。用到其他人体上需要配准或按骨度比例映射。
  • Distance to bone is geometric.到骨距离是几何量。 bone_distance_mm is the straight-line distance from the point to the nearest bone surface in this model, not a needling depth.bone_distance_mm 是模型中从该点到最近骨表面的直线距离，不是进针深度。
  • Surface course only.只有体表循行。 The meridian lines show the course on the skin; internal pathways are not included.经线只表示皮肤上的循行，不含体内循行。
  • Not medical advice.不构成医疗建议。 The dataset is made for research and teaching. It is not a clinical reference and does not replace professional training.本数据集用于科研和教学，不是临床依据，也不能代替专业训练。
  • Display on this website.本站的显示方式。 A garment covers the pelvis of the body shown here. The 51 points under it are drawn on its surface; their coordinates in the data remain on the skin.本站显示的人体在骨盆处穿有衣物。被衣物覆盖的 51 个点画在衣物表面；数据中的坐标仍在皮肤上。
